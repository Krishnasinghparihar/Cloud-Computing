# EC2 Static Website Hosting

This project demonstrates hosting a static website on AWS EC2 using Apache web server.

## Problem Statement
Host a static informational website on cloud with full control over the server environment.

## Steps Performed
1. Launched an EC2 instance
2. Configured security group for SSH (22) and HTTP (80)
3. Connected to EC2 using SSH
4. Installed Apache web server
5. Deployed static HTML website in /var/www/html
6. Accessed website using public IP

## Tools Used
- AWS EC2
- Apache HTTP Server
- Linux
